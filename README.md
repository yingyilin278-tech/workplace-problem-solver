# 职场问题解决顾问

一个面向中文职场与求职场景的 Agent Skill。它把模糊困扰拆成可判断的问题，再给出可以直接使用的沟通话术、行动方案、留痕建议和风险边界。

> 这不是“教人赢下办公室斗争”的话术库。它优先保护用户的目标、关系、证据和退路，不把猜测当事实，也不把强硬误当有效。

## 能解决什么问题

### 在职场景

- 向上沟通、任务澄清、临时加活与优先级冲突
- 同事协作、跨部门推诿、成果归属与背锅风险
- 汇报表达、绩效反馈、晋升、薪酬与职责边界
- 加班、职业倦怠、心理内耗与岗位匹配
- PIP、调岗、降薪、裁员、离职与职业转向
- 管理者带团队、授权、反馈和冲突处理

### 求职场景

- 求职方向与定位
- 经历盘点、简历与 JD 匹配
- 自我介绍、项目叙事和模拟面试
- Offer 比较、谈薪与面试复盘

### 知识蒸馏

- 把已获授权或可合法访问的书籍、论文、访谈、课程、视频字幕和内容素材，整理成可检索、可追溯、可执行的职场知识卡

## 它怎么工作

Skill 会先区分事实、解释、感受和目标，然后：

1. 判断属于在职问题（C1–C12）还是求职问题（J1–J7）。
2. 只收集会改变判断或风险等级的必要信息。
3. 找到最早的不可逆节点，例如辞职、签字、承认过错、公开冲突或删除证据。
4. 比较低冲突、平衡和强边界方案的收益、代价与可逆性。
5. 固定输出“判断、建议、话术、后续、风险”五个部分。

示例输出结构：

```markdown
## 判断

## 建议

## 话术

## 后续

## 风险
```

## 安装

### 使用 Skills CLI

```bash
npx skills add yingyilin278-tech/workplace-problem-solver
```

### Codex

将 `workplace-problem-solver` 目录复制到：

```text
~/.codex/skills/workplace-problem-solver
```

重启或重新打开 Codex 后即可使用。

### Claude Code

将 `workplace-problem-solver` 目录复制到：

```text
~/.claude/skills/workplace-problem-solver
```

### 手动安装

下载本仓库，把包含 `SKILL.md` 的 `workplace-problem-solver` 文件夹放入你的 Agent 所使用的 Skills 目录。不同 Agent 的目录和加载方式可能不同，请以对应产品文档为准。

## 使用示例

安装后可以直接描述问题：

```text
领导周五晚上临时让我周一交一份原计划需要三天的报告，
但我手上还有两个已承诺的任务。帮我判断怎么回复，既不直接拒绝，
也不要默认把所有责任接下来。
```

```text
这是目标岗位的 JD 和我的简历。请判断匹配度，找出证据不足的部分，
改写项目经历，并准备面试官最可能追问的五个问题。
```

```text
HR 给了我一份 PIP，让我今天签字。请帮我区分事实、风险和待确认事项，
先给我一段不对抗但能保留核实空间的回复。
```

## 数据来源与知识等级

本项目不会把“被列入书库”等同于“已阅读全文并验证”。资料按证据状态分层：

- L0：候选线索
- L1：元数据或来源已核验
- L2：已形成结构化规则、动作、话术、反例与边界
- L3：通过案例测试和人工复核

来源目录会记录标题、作者、链接、用途、证据状态和使用限制。书籍及论文的版权归原作者和出版方所有；仓库中的知识卡是面向工作流的结构化摘要，不提供或替代受版权保护的原文。

## 公开声明

本项目以开源、可检查、可纠正为原则公开发布：

- 不声称能准确读取他人动机，也不会仅凭单一描述给人贴上“PUA、打压、嫉妒”等标签。
- 不鼓励报复、操纵、歧视、骚扰、违法取证或绕过组织制度。
- 不收集、不上传用户的简历、聊天记录、劳动合同、公司文件或其他个人资料；这些材料是否被发送到模型服务，取决于用户选择的 Agent、模型供应商和运行环境。
- 仓库内不应提交真实个人信息、公司秘密、访问令牌或未经授权的材料。
- 涉及法律、医疗、人身安全或严重心理危机时，本 Skill 只做风险识别、信息整理和求助路径提示，不替代律师、医生、心理专业人员或紧急服务。
- AI 输出可能出错。重要决定应结合原始文件、当地规则、所在组织制度和合格专业人士意见，由用户自行复核。

更多说明见 [`NOTICE.md`](NOTICE.md) 和 [`SECURITY.md`](SECURITY.md)。


```bash

```

评估覆盖在职问题、求职子域、五段输出协议和高风险分流。测试报告是特定版本下的结果，不代表所有模型、所有提示或真实场景均能达到相同表现。
