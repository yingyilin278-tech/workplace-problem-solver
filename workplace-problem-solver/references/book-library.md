# 职场问题解决开放书库

本书库用于“检索和选择资料”，不代表这些书已经全部读完或全部可以直接影响答案。相关书籍不存在可穷尽的“全网全部”；当前版本收录 100 本高相关书籍，并允许后续扩充。

## 启用等级

- **L0 候选**：书目信息待进一步核验，只能作为检索线索。
- **L1 已核验**：已核对出版社、作者或正式书目介绍，可进入蒸馏队列。
- **L2 已蒸馏**：已经形成判断规则、行动步骤、话术、反例和适用边界。
- **L3 已测试**：蒸馏规则经过案例测试和人工复核，可进入正式回答层。
- 劳动法律书籍还必须标注地区、版本和法规核验日期；即使达到 L3，也不能替代专业法律意见。

## 使用限制

1. 每个问题最多选择 3 本核心书、2 本补充书、1 本反方或反例书，不能把 100 本同时塞进一次回答。
2. L0 只能用于发现线索；L1 只能形成待验证假设；L2 才能提供规则候选；L3 才能稳定进入回答。
3. 一本书不能同时承担事实判断、法律结论和话术生成。事实优先由论文、制度或原始证据支持。
4. 对话书在欺凌、骚扰、报复或逼签场景中必须降权，先保护证据、选择权和人身安全。
5. 中国劳动法律书籍必须与回答当天的现行法律、司法解释和属地规则交叉核验。
6. 不因畅销、名人推荐或作者成功经历提高证据等级。
