# 第二轮20本书中文蒸馏索引

详细来源、行动、话术和反例见对应 `references/knowledge/book-b*.md`；出现规则冲突时读 `core-book-conflicts.md`。

| ID | 核心判断规则 | 主要动作 | 关键反例或边界 |
|---|---|---|---|
| B16 | 新要求冲突时，把容量后果变成两个可执行组合交给有权限者选择 | 找利益和约束，比较范围、时间、资源和替代方案 | 对方没有决策权时，继续谈组合不会产生有效决定 |
| B17 | 领导要求模糊时，先确认结果、优先级、期限和检查节点 | 适配沟通方式，但用书面确认保护任务口径 | 适配风格不能补足缺失的资源和权限，也不能解决报复 |
| B21 | 图表设计从受众要做的决定开始，而不是从“做什么图”开始 | 核验数据定义，删除无关视觉元素，突出比较和不确定性 | 漂亮叙事会让错误或偏差数据更有说服力 |
| B22 | 演示前先明确受众利益、所需决定和下一步，并正面处理可预见异议 | 建受众地图，用证据、权衡和实施细节回应反对 | 故事和情绪不能隐藏重要事实、风险与不确定性 |
| B28 | 可改进的绩效问题必须说清行为、标准、影响、期望、支持和复查日 | 私下给反馈，先核实上下文，再形成书面约定 | 高频反馈如果模糊、公开、前后不一或带报复性仍然有害 |
| B29 | 评价某项职责前，必须确认标准事先传达且在周期内可观察 | 用期望—实际—证据—影响—下一结果代替人格标签 | 漂亮的绩效面谈不能修复事后改变或资源上不可能的目标 |
| B34 | 新任务超过容量时，必须说明哪项原任务会延期、缩减或降质 | 设置日历、会议、渠道和响应边界，并要求有权者取舍 | 时间管理无法解决总工时本来就超过容量的问题 |
| B36 | 长期耗竭同时伴随低落、兴趣丧失、绝望或功能受损时，先寻求专业评估 | 同时检查症状严重度和具体工作压力源 | 一次高峰期疲劳不能自行诊断为抑郁或倦怠 |
| B37 | 反复思考同一威胁却没有新增证据或行动时，先使用心理距离停止循环 | 用第三人称、自我建议、时间距离，再回到下一动作 | 心理距离不能变成回避情绪或拖延必要对话 |
| B38 | 把想法当事实或身份时，先标记“我正在产生这个想法”，再按价值行动 | 识别情绪和故事，选择小而一致的下一步 | 接纳情绪不能被用来劝人接受欺凌、歧视或不安全环境 |
| B40 | 工作挫折被理解成整个人生失败时，先恢复非工作身份和需求来源 | 区分收入、意义、归属、地位和创造力应由哪里满足 | 有意义的事业不必然有害，前提是自愿、可恢复且有其他身份 |
| B43 | 新岗位必须先识别转换类型和授权，再套通用90天计划 | 调整学习重点、利益相关者关系、领导方式和早期成果 | 危机、违规或安全事件不能用长期诊断拖延即时行动 |
| B46 | 转行目标抽象时，先做访谈和工作样本，再花大钱培训或裸辞 | 建财务模型、技能差距和小规模现实测试 | 副业体验不能完整代表全职岗位的节奏、政治和经济条件 |
| B47 | 无正式权力协作时，先澄清结果、责任、依赖和决策人 | 把跨部门请求转成共同目标、明确取舍和书面确认 | 调整表达无法解决双方激励根本冲突或明确恶意 |
| B48 | 卡在“唯一正确道路”时，先设计多个可行未来并做低成本原型 | 进行信息访谈、体验实验和可逆选择 | 单个访谈可能代表极端个案，实验也要考虑家庭和财务约束 |
| B51 | 新经理先理解团队目的和每个人的工作，再大改流程 | 建稳定一对一、明确标准、支持、授权和复查 | 增加一对一不能替代清晰目标、资源和决策权 |
| B52 | 对方拥有问题和决策空间时，先提问再给建议 | 找真正挑战、需要什么、承诺做什么，减少管理者抢答 | 管理者本应决策或安全合规紧急时，连续提问会显得推责 |
| B53 | 团队分歧先统一共同目标、决策人、标准和期限 | 明确依赖、负责人、交接标准和升级路径 | 高层用相互冲突的指标奖励各部门时，团队口号无法解决问题 |
| B57 | 临时、跨专业、高不确定协作要快速建立共同目的、专家地图和学习循环 | 先收集独立意见，复盘假设和结果，持续更新协作方式 | 稳定重复工作更需要标准作业；紧急指挥不宜拖延收敛 |
| B71 | 中国员工关系事项涉及工资、职责、处分、合同和离职时，先核现行法与属地程序 | 把教材用于建立问题清单，再查权威法源和专业意见 | 教材案例可能被新司法解释或当地裁判口径替代 |
