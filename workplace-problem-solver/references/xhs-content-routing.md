# 职场小红书内容层接入规则

## 目的

把 `xhs-content-knowledge/` 接到现有 `workplace-problem-solver` 中，但不让它越权。

这层的定位是：

- 补充中文语境
- 补充现实表达方式
- 补充具体场景案例

而不是替代：

- 书籍规则
- 论文边界
- 法律核验
- 医疗和心理专业支持

## 使用优先级

默认顺序：

1. 主类别规则：`decision-rules.md`
2. 风险边界：`risk-boundaries.md`
3. 书籍 / 论文 / 官方视频
4. 小红书内容卡

小红书内容卡默认只做：

- 场景补充
- 中文话术风格补充
- 案例线索补充

不默认单独承担最终判断。

## 可优先使用的类别

小红书内容卡优先用于：

- C1 任务安排与向上沟通
- C2 领导关系、打压与 PUA
- C3 同事冲突与成果归属
- C5 工作量、加班与职业边界
- C6 汇报表达与职场存在感
- C7 绩效、薪酬与制度公平
- C8 晋升、成长与岗位匹配
- C10 职场人际与心理内耗
- C11 离职、裸辞与职业转向
- C12 管理者、带团队与下属协作

## 必须降权的类别

以下类别，小红书内容只能做辅助，不能单独决定建议：

- C9 PIP、调岗降薪与裁员
- 涉及仲裁、赔偿、签字、法定期限的问题
- 涉及创伤、严重心理危机、人身安全的问题

## 选卡方式

每次最多引用：

- 2 张小红书内容卡

并且必须满足：

- 不是同一作者重复同义表达
- 至少有 1 条边界信息
- 不与主规则直接冲突

## 冲突处理

如果小红书内容卡与书籍 / 论文 / 风险边界冲突：

1. 优先看风险更高的那一侧；
2. 优先看可逆性更强的建议；
3. 优先看证据更稳定的来源；
4. 小红书内容不能推翻法律或安全边界。
