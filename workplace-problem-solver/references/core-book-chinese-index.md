# 20本核心书中文蒸馏索引

本文件用于快速选书。详细来源、行动、话术和反例见 `references/knowledge/book-b*.md`；出现规则冲突时读 `core-book-conflicts.md`。

| ID | 核心判断规则 | 主要动作 | 关键反例或边界 |
|---|---|---|---|
| B01 | 对事实或动机有分歧时，先分开可观察事件、实际影响和动机推断 | 写事实/解释两栏，用“双方版本存在差异”开场 | 逼签、报复、骚扰或法定期限不能只靠探索性对话 |
| B02 | 立场冲突时先找利益、约束和替代方案；协议不能差于现实可行的退路 | 列利益和权限，生成范围/时间/资源组合，用客观标准比较 | 对方没有决策权或所谓客观标准被选择性执行 |
| B03 | 反馈让人抗拒时，区分真相触发、关系触发和身份触发 | 要求具体行为、影响、标准、例证和下一步 | 反馈只是为预定的不利决定补理由时，不能只强调开放心态 |
| B04 | 拒绝前先明确自己要保护的“是”，再表达清晰的“不”和可行建议 | 给取舍式选项，简短重复边界，要求确认 | 普通职责内的不便不能被包装成不可谈判的边界 |
| B05 | 高不确定、高协作工作必须主动邀请提问、异议和错误报告 | 明确工作不确定性，用具体问题邀请发声，先感谢再调查 | 心理安全不能替代能力、资源、标准和公平问责 |
| B06 | 向上管理的重点是对齐目标、优先级、沟通方式和可见结果 | 把新增任务变成取舍题，周期性关联结果与领导目标 | 不能把适应领导升级成忍受羞辱、歧视或长期报复 |
| B07 | 普通职场摩擦优先用简短、直接、专业的事实—影响—请求处理 | 先确认归口，再私下沟通，权益事项书面留痕 | 暴力、工资、歧视和正式处分不能只靠一句话术 |
| B08 | 高风险、高分歧、高情绪同时出现时，先恢复对话安全再谈内容 | 明确共同目的，陈述事实和暂定解释，形成谁在何时做什么 | 共同目的不能掩盖真实权利冲突或报复风险 |
| B09 | 信息中出现人格标签和动机指控时，改写成观察、影响/感受、需要和具体请求 | 提出可以回答的请求，并听取对方需要 | 共情不能替代欺诈、骚扰、安全和重复不履职的问责 |
| B10 | 冲突是否处理，取决于频率、工作影响、关系价值、双方风格和安全性 | 在直接谈、第三方、设边界、暂不处理和退出之间选择 | 把人固定为“冲突型人格”会忽略文化、情境和权力 |
| B11 | 困难行为类型只能作为临时假设，策略必须针对可观察机制 | 记录行为影响，选一个可逆策略，观察两三次互动 | 风险提示者不一定消极，详细检查不一定是控制欲 |
| B12 | 难缠行为常受激励、场景和旁观者结构影响，改变环境有时比劝人更有效 | 调整发言顺序、书面归属、检查点和升级证据 | 强势发言可能来自专业责任，贡献差异可能来自资源或合理便利 |
| B13 | 有效反馈必须同时包含真实关心和直接挑战，并具体到行为和结果 | 管理者先主动索取反馈，再私下及时给具体反馈 | 用“坦率”包装羞辱、人格攻击或单向权力不是有效反馈 |
| B15 | 正式流程解释不了决策时，需要识别非正式影响者、利益和预沟通 | 画权力/利益地图，建立真实关系，让成果可见 | 不能用办公室政治为流言、欺骗、抢功或泄密辩护 |
| B20 | 面向决策的表达先给答案，再给同一层级、逻辑有序的支持 | 写一句决策问题和结论，按时间/结构/重要性组织论据 | 调解、共同探索和事实不明时，结论先行可能显得结果已定 |
| B27 | 绩效争议应回到事前标准、约定目标、同期证据、资源条件和一致适用 | 分开事实与评级标签，核对标准、反馈、支持和申诉节点 | 高频反馈若仍模糊、无记录或带报复性，不会自动更公平 |
| B35 | 多人长期耗竭时，先检查工作量、控制、回报、共同体、公平和价值冲突 | 量化工作条件，提出减量、延期、补人、授权或恢复安排 | 严重、持续和跨场景的功能受损需要专业评估，不能自行诊断 |
| B42 | 新岗位先判断转型类型、授权和成功标准，再复制旧经验或追求早期胜利 | 建学习议程、利益相关者地图和可逆早期成果 | 早期胜利不能牺牲程序、公平、安全或把成本转嫁给其他团队 |
| B50 | 管理者应找高杠杆活动，指标必须同时覆盖数量、质量、时效和未来能力 | 找限制环节，按具体任务成熟度调整指导和授权 | 单一产出指标会诱发游戏化、过载、质量下降和不公平 |
| B70 | 中国大陆劳动事项先识别法律依据、合同制度、证据、通知和程序，再核验现行法与属地口径 | 建时间线，合法保存材料，把书当问题清单而不是最终答案 | 企业风控视角不等于员工公平；版本、地区和法律变化可使模板失效 |
