# 职场小红书内容蒸馏规范

## 目标

把小红书里的**单条笔记正文、视频字幕或详情页可见文本**蒸馏成可检索、可追溯、可执行的职场内容卡，供 `workplace-problem-solver` 在回答真实问题时调用。

这层不是账号定位库，也不是爆款分析库。它的目标只有一个：

> 把“某条具体内容讲了什么”变成结构化规则、动作、话术和边界。

## 前置条件

只有满足以下任一条件，才进入内容级蒸馏：

1. 拿到笔记正文；
2. 拿到视频字幕或可靠转写；
3. 拿到详情页中足够长的正文片段；
4. 能明确区分标题、正文、评论、作者简介。

不满足时，只能停留在：

- `creator-knowledge/` 账号定位级卡片
- 或 `source-catalog.md` 的待蒸馏条目

## 内容卡字段

每张内容卡必须包含：

- XHS 内容 ID
- 作者昵称
- 原始链接
- 内容类型：图文 / 视频 / 混合
- 文本来源：正文 / 字幕 / 详情页摘录 / 人工转写
- 抓取日期
- 关联问题类别：C1-C12
- 核心主张
- 判断规则
- 行动步骤
- 可直接使用的话术
- 反例与不适用条件
- 风险边界
- 证据级别

## 证据级别

- **X1**：正文或官方字幕完整，能稳定识别主张
- **X2**：正文不完整，但关键段落足够，能提炼局部规则
- **X3**：只有标题或短摘录，只能保留为线索，不进正式回答层

## 蒸馏规则

### 1. 只蒸馏具体内容，不蒸馏账号想象

错误：

> 这个博主大概率主张“先拒绝再沟通”。

正确：

> 这条内容主张：先确认事实，再书面化风险，再决定是否正面拒绝。

### 2. 不把流量表达直接写成判断规则

很多小红书内容为了传播，会使用：

- 极端标题
- 强情绪句子
- 单案例放大
- 绝对化结论

蒸馏时必须拆分为：

- 可观察事实
- 讲者主张
- 可执行动作
- 适用边界

### 3. 必须加边界

如果内容涉及：

- 劳动法
- 仲裁
- 裁员
- PIP
- 心理健康
- 创伤

必须显式写明：

- 不能替代法律或医疗意见
- 需要哪些补充信息
- 哪些情境不适用

### 4. 输出要能进入现有五段协议

内容卡不是为了“收藏观点”，而是为了以后能进入：

- `判断`
- `建议`
- `话术`
- `后续`
- `风险`

所以每张卡都必须能反推出至少：

1. 一个判断规则
2. 一个行动步骤
3. 一段可改写话术
4. 一个边界或反例

## 内容卡存放位置

- 单条内容卡：`references/xhs-content-knowledge/`
- 输入清单：`data/xhs-content-input/`
- 中间结果：`data/xhs-content-raw/`

## 什么时候能进入正式回答层

只有同时满足以下条件，才可作为正式候选来源：

1. 至少是 `X1` 或 `X2`
2. 已映射到 `C1-C12`
3. 有判断规则
4. 有行动步骤
5. 有话术
6. 有边界

否则只能作为：

- 选题线索
- 补充语感
- 次级参考
