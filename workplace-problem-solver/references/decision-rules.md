# 初版决策规则

这些规则是可测试的工作假设，不是法律或医疗结论。来源 ID 见 `source-catalog.md`；目前多为摘要级蒸馏，获得合法全文后再校正。

## C1 任务安排与向上沟通

- **判断规则**：若新任务必然挤压已确认任务，核心问题是决策权和优先级，不是用户“愿不愿意努力”。若目标、标准或期限不清，先确认再执行。[B02][P07]
- **行动步骤**：列出现有任务与后果 → 提供两个可执行选项 → 请有权人确认 → 留下最终口径。
- **话术骨架**：“可以接。按目前容量，若今天启动 C，A 会顺延到周二；如果 A 仍按原期，需要增加___。请确认优先级。”
- **反例**：任务可在正常容量内完成，用户只是因不喜欢而拒绝；此时先澄清责任而非制造优先级冲突。

## C2 领导关系、打压与PUA

- **判断规则**：一次严厉反馈不能证明打压；持续敌意表达、标准反复、公开羞辱、资源撤回或逼退动作重复出现时，风险上升。[P02]
- **行动步骤**：记录行为和频率 → 要求具体标准 → 对比后续是否一致 → 出现权益动作时转高风险流程。
- **话术骨架**：“为了改进，我想确认这次未达标的具体行为、对应标准和下次验收证据。我会整理后与你确认。”
- **反例**：对方给出一致标准、具体示例和支持资源，且对团队普遍适用；这更接近高要求管理。

## C3 同事冲突与成果归属

- **判断规则**：先区分任务分歧和关系攻击；关系冲突通常会损害满意度和绩效，不能把公开羞辱包装成“为了把事做好”。[P05]
- **行动步骤**：重建时间线 → 展示版本和交付 → 纠正当前责任 → 约定后续分工与汇报方式。
- **话术骨架**：“我补充同一时间线：___日我完成___，___日收到变更。当前需要确认的是___，相关版本在附件。”
- **反例**：用户确实漏交关键事项；此时应承认具体缺口，同时拒绝承担未发生的责任。

## C4 跨部门协作与会议推进

- **判断规则**：没有负责人、交付物、期限或升级人的会议不构成闭环。冲突来自资源约束时，单纯催促不会解决。[P05][P07]
- **行动步骤**：确认共同结果 → 拆依赖 → 指定责任人与交付物 → 设置节点 → 写明卡点升级条件。
- **话术骨架**：“为保证___按期交付，今天确认四项：负责人___、输入___、截止___、超过___时升级给___。”
- **反例**：负责人明确但能力或资源不足；此时继续强调责任会放大冲突，应先补资源或调范围。

## C5 工作量、加班与职业边界

- **判断规则**：长期高要求且缺少时间、资源、控制感或恢复机会时，耗竭风险更高；不要把结构性超载解释成个人效率问题。[P03]
- **行动步骤**：量化任务和容量 → 区分一次急活与长期超载 → 提出删范围、延时间、加资源 → 记录健康与交付影响。
- **话术骨架**：“当前量按正常质量需要___小时。本周可选：缩到___、延期到___，或增加___支持，请确认。”
- **反例**：短期可控紧急事件且有补偿和恢复安排；不应机械套用长期边界冲突。

## C6 汇报表达与职场存在感

- **判断规则**：汇报的目标是帮助决策，不是罗列劳动过程。具体目标与反馈通常比“做好一点”更可执行。[P01][P07]
- **行动步骤**：先给结论 → 给最少证据 → 说明风险 → 提出需要的决定 → 确认下一步。
- **话术骨架**：“结论是___；证据有___；当前风险是___；需要你在___前决定 A/B，我随后___。”
- **反例**：涉及争议责任或高风险事项时，过度压缩细节可能损失证据，应附完整时间线。

## C7 绩效、薪酬与制度公平

- **判断规则**：把公平拆成结果分配、程序、对待方式和信息解释四部分；“结果不好”不自动等于程序不公。[P04]
- **行动步骤**：取得事前标准 → 对照结果证据 → 确认决策人和流程 → 提出具体差异 → 记录答复。
- **话术骨架**：“我想核对___指标的评分依据。我的完成证据是___；请说明差距、评分口径和下次达到___所需结果。”
- **反例**：只用同事表现作比较但不了解对方目标；这种比较证据弱，应回到自己的标准和结果。

## C8 晋升、成长与岗位匹配

- **判断规则**：工作能力与岗位要求不匹配，不能直接等同于“能力差”。要先区分能力缺口、目标/资源缺口、岗位要求变化和岗位错配；只有持续的结果落差且经过支持和验证仍无法改善，才提高转岗或离开权重。[B03][B42][P07]
- **行动步骤**：列岗位要求 → 对照实际工作证据 → 拆成会做/不会做/资源不足/岗位不适配 → 选择一项能力做 30-90 天验证 → 复查结果后决定补能力、换岗位或离开。
- **话术骨架**：“我想把当前岗位要求和实际差距逐项对齐。目前我能稳定完成的是___，主要卡点是___。如果在___前补齐___并交付___，是否可以作为继续匹配该岗位的验证标准？”
- **反例**：一次项目失败、一次反馈严厉或缺少培训，不能直接证明能力与岗位不匹配；反过来，长期被安排超出职责且没有资源，也不能简单归因于个人能力。

## C9 PIP、调岗降薪与裁员

- **判断规则**：出现签字、收入变化、岗位变化或解除节点时，先保护选择权和合法证据；通用管理研究不能替代当地法律。[P04][P07]
- **行动步骤**：确认地区与文件 → 标出最早不可逆节点 → 保存合法原始记录 → 书面提出事实问题 → 咨询合格专业人士。
- **话术骨架**：“我已收到文件。为准确理解，请书面说明依据、目标、评价方式、申诉渠道和生效时间。我会核对后正式回复。”
- **反例**：不应固定回答“签/不签”或“N/N+1”，因为合同、地区、程序和证据会改变结论。

## C10 职场人际与心理内耗

- **判断规则**：先分离可见行为和动机解释；重复忽视、排除和冷处理可作为排斥信号，但不能仅凭一次社交落差定性。[P08]
- **行动步骤**：写事实/解释两栏 → 选择一个低成本验证 → 找可信任反馈 → 评估对工作功能和健康的影响。
- **话术骨架**：“最近三次___信息我没有收到，已经影响___。后续请把我加入___渠道；若分工有变化，也请直接确认。”
- **反例**：团队只是临时调整沟通范围且工作未受影响；不应放大为系统性排挤。

## C11 离职、裸辞与职业转向

- **判断规则**：离职决策同时看健康/安全红线、现金缓冲、下一方向验证和留下成本；强烈情绪不是唯一决策标准。[B02][P03]
- **行动步骤**：列必须离开信号 → 算现金跑道 → 做外部访谈/投递试验 → 准备交接与退出 → 设日期决策。
- **话术骨架**：“基于个人规划，我计划在___结束工作。接下来我会完成___交接，并在___前确认清单。”
- **反例**：现实人身或健康危险已出现时，不应要求用户先完成长期市场验证再离开。

## C12 管理者、带团队与下属协作

- **判断规则**：先判断不会做、不愿做、目标不清或资源不足；团队敢于报告错误和问题是学习前提，问责不能以压制发声为代价。[P06][B05]
- **行动步骤**：明确标准 → 询问障碍 → 提供资源/反馈 → 设复查节点 → 行为持续时进入一致的正式流程。
- **话术骨架**：“这次差距是___，标准是___。我想先确认障碍属于目标、能力还是资源；我们约定___动作，并在___复查。”
- **反例**：严重诚信或安全违规不能只做辅导式沟通，应立即按制度升级。

## 求职子域决策规则

这些规则吸收了外部 GitHub 求职 skill 在“问题定义、输入输出、复盘闭环”上的做法，但最终仍使用本 skill 的统一五段交付。

## J1 方向定位与求职策略

- **判断规则**：若用户同时想解决“换方向、涨薪、上岸速度、城市限制”多个目标，先排序目标，否则后续所有简历和面试动作都会冲突。
- **行动步骤**：列目标岗位 → 列约束条件 → 找当前最强筹码 → 设计小范围验证投递 → 依据结果收缩方向。
- **话术骨架**：“我当前优先解决的是___，可接受的底线是___，因此先集中投___类岗位，不再同时铺太多方向。”
- **反例**：现金或时间压力极高时，不应先做长期理想路线探索，应优先确保上岸。

## J2 经历盘点与素材库

- **判断规则**：求职材料弱，很多时候不是“不会写”，而是没有把经历拆成可验证事实、动作和结果。
- **行动步骤**：列 5-8 段经历 → 为每段补背景、目标、动作、结果、证据 → 删除只有职责没有结果的表述 → 留下可复用素材库。
- **话术骨架**：“这段经历别只写负责___，改成：在___场景下，我做了___，结果是___，证据是___。”
- **反例**：如果用户经历确实很少，重点应放在放大项目质量和学习曲线，而不是伪造密集经历。

## J3 JD 解析与简历定制

- **判断规则**：一份简历投所有岗位，通常会同时损失关键词命中和证据密度；简历不过筛，先怀疑匹配度和表达，不先怀疑运气。
- **行动步骤**：提取 JD 前三要求 → 找对应经历证据 → 改成岗位语言 → 删除无关内容 → 检查是否有结果量化。
- **话术骨架**：“这个 JD 真正在筛的是___、___、___，你的简历里要把___改写到更靠前的位置。”
- **反例**：若 JD 的硬门槛用户完全不满足，继续优化文案也难过筛，应直接调整投递池。

## J4 自我介绍与项目叙事

- **判断规则**：面试表达差，常见原因不是“不会说话”，而是故事没有主线、没有结果、没有个人贡献边界。
- **行动步骤**：先写一句定位 → 再选 2-3 个核心项目 → 每个项目用“背景-目标-动作-结果-你的作用”讲清 → 为追问补细节。
- **话术骨架**：“我是___方向的___，过去主要做过___。其中最能代表我的项目是___，我负责___，最后带来的结果是___。”
- **反例**：如果项目本身结果普通，就不要硬吹“大 impact”，应转而强调复杂度、判断和执行质量。

## J5 面试准备与模拟追问

- **判断规则**：面试不是只背标准答案；只要一段经历经不起细节追问，面试官就会质疑真实性和深度。
- **行动步骤**：准备高频题 → 准备项目细节追问 → 用面试官视角挑漏洞 → 补证据、补数字、补决策逻辑。
- **话术骨架**：“这个决定当时有两个方案，我最后选___，因为___；如果重来一次，我会___。”
- **反例**：过度模板化、每题都用同一套 STAR 套路，会让回答显得僵硬且不可信。

## J6 offer 比较与谈薪决策

- **判断规则**：offer 不是只看总包；当前现金、岗位成长、团队质量、简历增值和退出可逆性都要一起看。
- **行动步骤**：列比较维度 → 标出硬风险 → 明确底线与想争取项 → 谈判时先确认范围，再提要求 → 为拒绝或接受保留关系。
- **话术骨架**：“我目前更倾向这份机会，主要因为___。如果薪资/级别能调整到___，我会更有把握尽快确认。”
- **反例**：若另一家 offer 并不稳定或并非真实在手，不应拿它做高强度施压。

## J7 面试复盘与下一轮优化

- **判断规则**：复盘必须落到具体失败节点；“感觉不太好”不能指导下一轮优化。
- **行动步骤**：按轮次重建问题 → 标记卡住点 → 区分筛选问题、表达问题、深度问题、匹配问题 → 回灌到 J1/J3/J4/J5。
- **话术骨架**：“这次主要不是答错，而是我在___问题上没有给出足够证据；下一轮我会把___提前放进简历/自我介绍/项目叙事里。”
- **反例**：把所有失败都归因于运气或面试官偏好，会阻断真实优化。
