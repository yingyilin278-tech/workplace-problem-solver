# 职场博主账号蒸馏总表

## 数据边界

- 来源：Just One API `/api/xiaohongshu/search-user/v2`
- 原始去重账号：665 个
- 相关账号：643 个
- 按账号昵称合并后的唯一昵称：596 个
- 这份文件蒸馏的是账号定位信号，不等同于博主视频或笔记正文。
- 只有昵称、简介、匹配关键词和分类能支持的内容才纳入；不能把推断写成博主明确观点。

## 账号蒸馏字段

每个账号档案包含：

- 账号昵称
- 粉丝数
- 主页链接
- 命中的搜索关键词
- 归属内容类别
- 搜索来源文件
- 证据置信度
- 可关联的职场问题

## 类别说明

| 类别 | 可关联问题 | 证据边界 |
|---|---|---|
| 求职与招聘 | 求职、简历、面试、校招、社招 | 只能说明账号被求职相关关键词检索到 |
| 沟通与管理 | 向上管理、职场沟通、领导力、管理者、带团队 | 只能说明账号定位或关键词命中 |
| 绩效与权益 | 绩效、裁员、PIP、劳动法、劳动仲裁、薪资谈判 | 法律内容必须另行核验，不能直接当法律意见 |
| 职场成长 | 职业规划、转行、晋升、职场干货 | 不能据昵称推断具体方法有效 |
| 心理与边界 | 职场心理、工作倦怠、反内耗、职场妈妈、职场女性 | 不能将账号定位等同于心理诊断或治疗 |
| 组织环境 | 大厂职场、外企职场、体制内职场 | 只表示场景方向，不代表适用于全部组织 |
| 办公技能 | Excel职场、PPT职场、工作效率 | 只能说明工具或效率方向 |

## 使用规则

1. 回答用户问题时，先按问题类别筛选账号档案。
2. 账号档案只用于说明“可能的内容方向”和“检索来源”。
3. 没有笔记正文、视频字幕或详情数据时，不得写成“某博主提出了某方法”。
4. 如果要蒸馏博主具体教学，必须补充该账号的视频字幕、笔记正文或详情接口数据。
5. 法律、心理健康和劳动仲裁相关账号只能作为线索，必须交叉核验。
