# 按问题选择资料

## 选择原则

- **书籍**：提供可复用框架和对话结构，不单独作为事实证据。
- **论文**：支持判断变量、风险信号和边界，不直接生成逐字话术。
- **视频**：观察真实表达、节奏和场景，不因演讲有感染力就提升证据等级。
- **小红书内容卡**：只在拿到单条正文、字幕或详情文本后使用；默认补充中文语感、现实案例和表达方式，不单独承担最终判断。
- 每次回答只加载与主问题最相关的少量知识卡；高风险结论还需核验当地制度或专业来源。
- 小红书内容卡每次最多使用 2 张，并且必须同时保留边界说明。
- 完整 100 本书库与 L0—L3 启用等级见 `book-library.md`。每题最多选择 3 本核心、2 本补充、1 本反方来源。

## 获取顺序

1. 先从 `book-library.md` 中选择与当前类别最相关的 L2 书籍，不读取无关书。
2. 先处理 P01—P08 的摘要、方法、结论和限制，用论文约束书籍中的一般化主张。
3. 用户提供合法书籍内容后，按章节蒸馏；不保存大段原文。
4. 取得官方字幕后蒸馏 V01—V05，保留时间戳并区分主张、案例和修辞。
5. 每张卡至少绑定一个类别、一个判断规则、一个反例和一个停止条件。
6. 规则通过案例测试后，才把对应书籍从 L2 提升到 L3。
