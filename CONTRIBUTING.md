# Contributing

## Before opening a change

1. Explain the workplace or job-search scenario the change improves.
2. Separate observed facts from interpretation.
3. State the expected behavior and the current failure.
4. Add or update a case when changing a decision rule.
5. Preserve the five-part output contract: 判断、建议、话术、后续、风险.

## Source requirements

For new research material, record:

- title, author or organization;
- stable source URL or DOI;
- source type and access date;
- evidence status and usage limitation;
- which rule or scenario it supports;
- counterexamples and boundaries.

Do not submit copied chapters, paywalled full text, private course materials, private messages, company documents or personal data.

## Code requirements

- Keep scripts deterministic and narrowly scoped.
- Do not add telemetry or network access without explicit documentation and user consent.
- Never hard-code credentials.
- Run relevant validation and include the command and result in the Pull Request.

## Human review

Changes involving dismissal, discrimination, harassment, self-harm, threats, medical claims or jurisdiction-specific law require stronger review. Prefer risk identification and evidence organization over definitive conclusions.
